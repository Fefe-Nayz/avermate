# Implementation Plans — Avermate × study-companion ("fishr") merge

Generated by the improve skill on 2026-08-14, at commit `46c966b` (branch
`rewrite`), extended the same day with wave-2, transversal and
sustainability plans (007–019).

**Product thesis (maintainer's words, 2026-08-14)**: a free, open-source
NotebookLM alternative fused with grade/performance tracking, in the spirit
of Papillon's provider aggregation (Moodle now; Pronote / EcoleDirecte /
Skolengo-class services evaluated) — every course source (PDF, link, pasted
text, lecture recording) centralized and AI-legible, studio outputs beyond
text (mind maps, slides/PPTX, later podcasts/videos), usable by ANY agent
the user prefers (MCP-first), with costly capabilities funded by BYOK /
self-hosted satellites / an optional paid tier rather than by gating the
core (see `docs/ai-architecture.md` and `docs/sustainability.md` once plans
007/019 land).

Context: four parallel audits of this repo plus the three prototype attempts
(`CoursePilot`, the `Fichr` repo, and the `Math-M. Coutens` working copy —
the latter two are the same remote, `github.com/Fefe-Nayz/Fichr`, branches
`main` = empty TS scaffold and `prototype` = the substantial Python system).

Execute in the order below unless dependencies say otherwise. Each executor:
read the plan fully before starting, honor its STOP conditions, and update
your row when done.

## Findings considered and rejected (do not re-audit)

- **Port any TypeScript from the `Fichr` scaffold** — generator output plus
  an orphaned component gallery; mine only the *prototype branch* design.
- **Salvage the prototype's FastAPI backend** — thin unauthenticated
  wrappers around Python modules being ported anyway.
- **Port the Windows SAPI TTS provider** — Windows-only fallback; drop.
- **Port dead prototype config** (`moodle_section_ids`, `auto_sync`,
  `sync_interval_hours`, `parallel_uploads`) — parsed, never read.
- **A general scheduling-calendar library for the agenda** — contradicts the
  recorded removal decision in `grade-calendar.tsx:24-38`.
- **Opening the widget registry now** — deliberately closed world; the card
  gallery (015) works within it.
- **`preferences` JSON-column retrofit** — enforce the typed-JSON convention
  on NEW tables only, for now.
- **History rewrite of `CoursePilot`** — no secret ever committed; archive.
- **Prototype-repo secret rotation** — verified unnecessary (nothing
  committed). Two real items tracked OUTSIDE these plans:
  `webapp/data/chats.db` IS tracked on `Fichr@prototype` — untrack/purge
  before that repo is ever public; and the Moodle token transited unverified
  TLS — regenerate once plan 008's TLS-verified sync works.
- **An `execute_command`-style agent tool** — banned by the ADR (007).
- **`fluid-tailwind` / `fluidwind`** — maintainer's own research (TODO.md)
  picked `tailwind-clamp`; `@jalendport/tailwindcss-fluid` watched pending
  npm publication.
- **Freeform-canvas mindmap editing / slide theming in v1** — 017 scopes to
  outline-driven maps and text slides; gold-plating deferred.
- **Storing school passwords for connectors** — sealed device tokens only
  (018 hard rule).
